CLOUD SECURITY BEST PRACTICES GUIDE

CHAPTER 1: CLOUD SECURITY FUNDAMENTALS

1.1 Shared Responsibility Model
In cloud computing, security responsibilities are divided between the cloud provider and the customer:

Cloud Provider Responsibilities:
- Physical data center security
- Network infrastructure
- Hypervisor and host security
- Hardware maintenance

Customer Responsibilities:
- Data encryption and classification
- Identity and access management
- Application security
- Operating system patches
- Network configuration
- Endpoint protection

1.2 Security Categories

Preventive Controls:
- Firewalls and security groups
- Access controls and IAM
- Encryption at rest and in transit
- Vulnerability scanning
- Security training

Detective Controls:
- Log aggregation and analysis
- Intrusion detection systems
- Security information and event management (SIEM)
- Cloudtrail logging
- Configuation monitoring

Corrective Controls:
- Incident response procedures
- Backup and recovery
- Disaster recovery planning
- Patch management

1.3 Cloud Security Frameworks

OWASP Cloud Security:
- Secure design principles
- Configuration management
- Identity and access management
- Data protection
- Incident response

CIS Cloud Benchmarks:
- AWS, Azure, GCP security benchmarks
- Vendor-agnostic recommendations
- Detailed configuration guidance

SOC 2 Compliance:
- Security, availability, processing integrity
- Confidentiality and privacy
- Trust service criteria

CHAPTER 2: IDENTITY AND ACCESS MANAGEMENT

2.1 Principle of Least Privilege
Users and services should only have the minimum permissions necessary to perform their tasks.

Implementation:
- Start with no permissions
- Add permissions as needed
- Regular access reviews
- Just-in-time access provisioning

2.2 Identity Providers

AWS IAM:
- Users, groups, roles, policies
- Federation with SAML 2.0
- Cross-account access
- Temporary credentials

Azure Active Directory:
- SaaS application integration
- Conditional access policies
- Identity protection
- Privileged identity management

Google Cloud IAM:
- Resource hierarchy
- Organization, folder, project, resource
- Service accounts
- Workload identity federation

2.3 Multi-Factor Authentication

MFA Methods:
- SMS (not recommended)
- Email verification codes
- TOTP (Google Authenticator, Authy)
- Hardware keys (YubiKey)
- Biometrics

Best Practices:
- Require MFA for all privileged accounts
- Require MFA for console access
- Require MFA for API access
- Implement adaptive MFA based on risk

2.4 Service Account Management

Service Account Best Practices:
- Use service account keys rarely
- Prefer workload identity federation
- Rotate keys frequently
- Restrict key usage by IP
- Monitor service account activity

CHAPTER 3: NETWORK SECURITY

3.1 Virtual Private Cloud Design

VPC Architecture:
- Public, private, and isolated subnets
- Network segmentation by function
- Availability zone distribution
- Transit gateway for hub-spoke

Subnet Design:
- Web tier: Public-facing, load balancers
- Application tier: Private, compute instances
- Data tier: Isolated, database instances
- Management tier: Bastion hosts, jump boxes

3.2 Security Groups and Firewalls

Security Groups (Stateful):
- Instance-level firewalls
- Allow rules only
- Default deny
- Reference other security groups

Network ACLs (Stateless):
- Subnet-level firewalls
- Allow and deny rules
- Evaluated before security groups
- Stateless packet filtering

3.3 Load Balancers and Proxies

Application Load Balancers:
- Layer 7 routing
- SSL/TLS termination
- Target groups and health checks
- Sticky sessions

Network Load Balancers:
- Layer 4 routing
- High performance
- Static IP addresses
- Cross-zone balancing

API Gateway Security:
- Request throttling
- API keys and usage plans
- Cognito integration
- WAF integration

3.4 VPN and Direct Connect

Site-to-Site VPN:
- Encrypted tunnel over internet
- Quick deployment
- Redundant connections
- Dynamic routing with BGP

AWS Direct Connect:
- Dedicated private connection
- Consistent network performance
- Higher throughput
- Connection to AWS global network

3.5 DDoS Protection

AWS Shield:
- Standard: Included at no cost
- Advanced: Paid tier, comprehensive protection

CloudFront:
- CDN with DDoS protection
- Edge caching
- Geographic restrictions
- Rate limiting

WAF (Web Application Firewall):
- SQL injection protection
- XSS protection
- Rate-based rules
- IP blocking

CHAPTER 4: DATA ENCRYPTION

4.1 Encryption at Rest

Storage-Level Encryption:
- EBS volumes: AES-256
- S3: Server-side encryption (SSE-S3, SSE-KMS, SSE-C)
- Database: TDE (Transparent Data Encryption)
- Glacier: Server-side encryption

Key Management:
- AWS KMS: Integrated key management
- Customer Managed Keys (CMK)
- Hardware Security Modules (HSM)
- Key rotation policies
- Key policies and grants

Client-Side Encryption:
- Encrypt before uploading
- Complete control over keys
- More complex implementation
- Best for sensitive data

4.2 Encryption in Transit

TLS/SSL:
- Encrypt data moving between services
- Use TLS 1.2 or higher
- Disable legacy protocols
- Certificate management

Certificate Management:
- AWS Certificate Manager
- Let's Encrypt
- Private CAs
- Auto-renewal
- Certificate transparency logs

4.3 Database Encryption

Relational Databases:
- RDS: Encryption at rest with KMS
- Aurora: Encryption with KMS
- PostgreSQL: pgcrypto extension
- SQL Server: TDE

NoSQL Databases:
- DynamoDB: At-rest encryption
- MongoDB: Field-level encryption
- Cassandra: Transparent data encryption

4.4 Data Loss Prevention

DLP Strategies:
- Identify sensitive data
- Classify data by sensitivity
- Monitor data movement
- Prevent unauthorized exfiltration

Implementation:
- Content inspection
- Pattern matching
- Data tagging
- Access controls

CHAPTER 5: CONTAINER SECURITY

5.1 Container Image Security

Image Scanning:
- Clair: Static analysis for containers
- Trivy: Vulnerability scanner
- Snyk: Container vulnerability management
- Amazon ECR: Integrated scanning

Image Hardening:
- Minimal base images (Alpine)
- Multi-stage builds
- No root users
- Signed images
- Minimal packages

Image Registry Security:
- Private registries
- Access control
- Pull through caches
- Regular image updates

5.2 Kubernetes Security

RBAC (Role-Based Access Control):
- Roles and ClusterRoles
- RoleBindings and ClusterRoleBindings
- Principle of least privilege
- Service account permissions

Network Policies:
- Default deny all
- Namespace isolation
- Ingress and egress rules
- DNS policies

Pod Security:
- Security context
- Pod security policies
- Resource limits
- Non-root containers

5.3 Secrets Management

Kubernetes Secrets:
- Base64 encoded (not encrypted)
- Not default encryption at rest
- External secrets operators
- HashiCorp Vault integration

External Secrets Management:
- HashiCorp Vault
- AWS Secrets Manager
- Azure Key Vault
- Google Secret Manager

5.4 Container Runtime Security

Runtime Protection:
- Falco: Runtime threat detection
- Sysdig: Container visibility
- Aqua Security: Container protection
- AppArmor/SELinux profiles

Isolation:
- Namespace separation
- Cgroup resource limits
- Seccomp profiles
- Capabilities dropping
